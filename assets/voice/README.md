# Amostra de voz sintética do Jarvis

`jarvis-demo.mp3` é uma frase fixa gerada em 18 de outubro de 2026 com o clone instantâneo GleysonSilva-Jarvis, na conta ElevenLabs do responsável pelo projeto, plano Creator. Modelo: Eleven Multilingual v2; MP3 44,1 kHz e 128 kbps. A referência de voz e as credenciais não são distribuídas.

Texto: “Olá, Gleyson. Eu sou o Jarvis. Estou pronto para conversar e ajudar nas suas tarefas. Você acompanha cada ação e mantém o controle.”

O responsável confirmou autorização para clonagem e distribuição pública do áudio. A amostra pode ser redistribuída como demonstração e como parte deste projeto, preservando este aviso de origem sintética. A licença Apache 2.0 do código não concede licença sobre a identidade vocal, as gravações originais, marcas ou modelos do provedor. A gravação não representa uma pessoa falando ao vivo.

O arquivo permite ouvir essa frase sem conexão com a API. Não contém um modelo de voz e não permite sintetizar novas respostas sozinho. Para frases novas, cada instalação precisa de um provedor de síntese e das permissões de acesso à voz escolhida. Clones instantâneos não são exportados como pesos independentes.

Condições do serviço: [publicação de conteúdo](https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform), [clonagem](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning).
