# Identidade visual do GleysonSilva-Jarvis

Arte vetorial original do projeto: núcleo circular ciano, monograma J e nome do assistente sobre fundo escuro. Estes arquivos seguem a licença Apache-2.0 do repositório.

- `logo.svg`: símbolo vetorial quadrado, 512 × 512.
- `social-preview.svg`: fonte vetorial da capa, 1280 × 640.
- `social-preview.png`: versão de compartilhamento, 1280 × 640, com fundo sólido e menos de 1 MB.

A capa é definida no GitHub em **Settings → General → Social preview → Edit → Upload an image…**. Salvar somente o PNG no código não altera essa configuração. Sem uma capa própria, o GitHub gera uma prévia que pode usar o avatar do proprietário da conta. Alterar a capa do repositório não altera o avatar usado em outros projetos.

O README usa a mesma imagem. As plataformas que já consultaram o link podem conservar uma cópia anterior até atualizar seu cache.
