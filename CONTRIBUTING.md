# Contribuir com o Projeto GleysonSilva-Jarvis

Use Node.js 24 ou superior. Instale com `npm install`, valide com `npm run verify` e abra com `npm start`. `npm run test:local` testa a interface no navegador com uma pasta de demonstração; não substitui os testes nativos Windows.

Descreva o comportamento observável, o motivo da mudança e como foi verificada. Inclua passos de reprodução para defeitos. Nunca anexe chaves, gravações de usuários, imagens de câmera, representações faciais, bancos de memória ou caminhos privados.

Ferramentas novas precisam de argumentos limitados, cancelamento e uma confirmação proporcional ao efeito. O modelo não recebe um terminal irrestrito. Conteúdo lido de páginas e documentos permanece dado não confiável. Uma operação iniciada só pode ser apresentada como concluída se o resultado tiver sido verificado.
